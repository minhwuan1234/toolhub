/Type.Family/ *Use the existing Toolhub system sans-serif typeface.*
/Type.Body/ *Use readable body text with enough line height for scanning and longer passages; the current app baseline is 16px with 1.5 line height.*
/Type.Heading/ *Use a clear hierarchy between the screen title, section headings, labels, and metadata. The screen title should be the strongest text level.*
/Type.Label/ *Keep field and control labels concise, visible, and close to the related control.*
/Type.Metadata/ *Use a smaller muted style for times, counts, helper details, and secondary status without making them unreadable.*
/Type.Truncation/ *Truncate only content that can be recovered elsewhere. Let requests, errors, and outputs wrap or scroll so their meaning is not lost.*
