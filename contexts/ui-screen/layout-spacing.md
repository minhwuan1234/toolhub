/Layout.Structure/ *Arrange the screen with a clear header, main content region, and supporting regions only when they serve the user goal.*
/Layout.Grid/ *Use a consistent alignment grid so titles, controls, content blocks, and edges line up.*
/Layout.Space/ *Use spacing consistently in small increments; increase space between sections more than between related items.*
/Layout.Width/ *Keep dense reading areas at a comfortable width. Let canvases use the available work area when panning or spatial work is central.*
/Layout.Modal/ *Use a dialog only for focused editing or confirmation. Let long dialog content scroll inside a stable header and viewport-safe container.*
/Layout.Order/ *Keep the visual order and keyboard order consistent.*
